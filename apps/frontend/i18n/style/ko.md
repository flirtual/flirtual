# Korean (ko)

Everything in this file is **provisional** until a native Korean reviewer confirms it.

The existing Korean translations are unreviewed machine output (DeepL). Don't use them as a
style reference.

## Register

- App, emails, push, and ban/warning notices: 해요체 everywhere, friendly and clear. Moderation
  notices stay polite and calm, never accusatory.
- Legal pages: 합니다체, in standard Korean terms-of-service style ("이용자" in third person).
- Other users: `{name}님`. Never bare `{name}`.
- Drop 당신/저 wherever a native app would. Korean apps almost never say 당신.

## Typography

- Standard Korean spacing (띄어쓰기) rules.
- Half-width punctuation and digits. Use “ ” or ‘ ’ for quotes, not 「」.
- Don't end buttons, labels or titles with a period.

## Avoid translationese

- Restructure sentences; don't mirror English word order or add subjects Korean omits.
- Use loanwords only where Korean apps do (프로필, 계정, 로그인 are fine).
- Rewrite jokes and puns for Korean, or make them a light line that works in Korean.

## Plurals

Korean has one plural category: `other`. Write only `other` (exact `=0`/`=1` may stay). Use
counters (명, 개, 번) as natural.
