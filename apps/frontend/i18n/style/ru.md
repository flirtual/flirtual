# Russian (ru)

Register and the Homie/Date terms are **provisional** until a native reviewer confirms them.
In particular, **вы vs ты** is an open question for a native reviewer.

## Register

- App, emails, push: **вы** for now (lowercase), friendly and warm rather than formal.
- Ban, warning and moderation notices: вы, polite and calm.
- Legal pages: usual Russian legal style, third person ("Пользователь"), no direct address.

## Terminology

| English | Russian |
|---|---|
| Homie (button) | Дружить ("хочет дружить с вами") |
| Homie Mode | Режим друзей |
| Homies (list) | Друзья |
| Date Mode | Режим свиданий (never Режим знакомств: знакомства overlaps with the friend mode) |
| Like (button) | Нравится (provisional) |
| Premium | Premium as the product name ("Flirtual Premium"); lowercase "премиум" as an ordinary adjective in running text |
| NSFW (feature) | NSFW |
| NSFW (disallowed) | обнажённость или откровенный сексуальный контент (provisional) |
| They/Them | они/их |
| She/Her, He/Him | она/её, он/его |

## Style

- Avoid gendered past-tense verbs about other users where possible ("{name} лайкнул(а)" is
  wrong); rephrase ("Вам поставили лайк", "У вас взаимная симпатия").
- Use «ёлочки» quotes and ё where it matters.

## Plurals

`one`, `few`, `many`, `other`: all four are required. `one` also covers 21, 31, …, so never
put a fixed word like "один" or "кто-то" in `one` when the count can be larger; use `#`.
